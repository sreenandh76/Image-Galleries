📸 Image Galleries

A modern and visually appealing image gallery built using React.js, designed to deliver a smooth and engaging browsing experience across all devices.

⸻

🚀 Features
	•	🖼️ Responsive image gallery layout
	•	⚡ Smooth scrolling navigation
	•	🎯 Clean and minimal UI design
	•	📱 Mobile-friendly footer with expandable sections
	•	🔍 Image preview popup support
	•	🎨 Stylish footer with social icons

⸻

🛠️ Tech Stack
	•	React.js
	•	HTML5
	•	CSS3
	•	JavaScript (ES6+)
